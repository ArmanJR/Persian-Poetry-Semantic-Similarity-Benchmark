# Experiment 5: Comprehensive Embedding Benchmark on LLM Explanations

This experiment benchmarks embedding models on **LLM-generated explanations** of Persian poetry, creating a **2D matrix** to compare:
- **9 Embedding Models** (from exp-3)
- **13 LLM Explanation Sources** (from exp-4)

This creates **117 combinations** to determine which embedding models and which LLM explanations work best for semantic similarity tasks.

## Overview

| Dimension | Options | Description |
|-----------|---------|-------------|
| **Embedding Models** | 9 models | OpenRouter embedding models that convert text to vectors |
| **Explanation LLMs** | 13 models | LLMs that generated Persian explanations of poetry |
| **Total Combinations** | 117 | Each embedding model tested with each LLM's explanations |

### Research Questions

1. **Which embedding models perform best overall?**
2. **Which LLM's explanations are most effective for embeddings?**
3. **Are there specific combinations that work exceptionally well?**
4. **Do explanations improve performance compared to raw poetry?** (Compare with exp-3)

## Methodology

### Two-Dimensional Benchmark

For each combination of (Embedding Model, Explanation LLM):
1. Load explanations generated by the specific LLM
2. Embed those explanations using the specific embedding model
3. Apply outlier detection (pairwise average similarity)
4. Calculate accuracy

## Usage

### Setup

1. Ensure you have your OpenRouter API key in the `.env` file:
   ```bash
   OPENROUTER_API_KEY=your_api_key_here
   ```

2. Install required dependencies:
   ```bash
   pip install numpy requests scikit-learn pandas python-dotenv
   ```

### Running the Full Benchmark

To test ALL 117 combinations:

```bash
cd exp-5
python openrouter_benchmark_all_explanations.py
```

**Time Estimate**: This will take significant time (several hours) due to:
- 117 combinations × 41 questions = 4,797 individual tests
- API rate limiting and caching will speed this up considerably

**Tip**: The script uses caching, so you can interrupt and restart without losing progress.

### Running for a Single Explanation Source

To test with just one LLM's explanations:

```bash
python openrouter_benchmark_explanations.py
```

Edit the `EXPLANATION_SOURCE_MODEL` variable to choose which LLM.

## Output Files

The benchmark generates multiple CSV files:

### 1. Detailed Results
**File**: `openrouter_results_all_explanations.csv`

Contains all 117 combinations with columns:
- `Embedding Model`
- `Explanation Model`
- `Accuracy (%)`
- `Correct` (number of correct predictions)
- `Total` (total valid questions)

### 2. Summary by Embedding Model
**File**: `summary_by_embedding_model.csv`

Aggregated statistics for each embedding model across all explanation sources:
- `Mean Accuracy` - Average performance across all 13 LLMs
- `Std Accuracy` - Standard deviation
- `Min Accuracy` - Worst-case performance
- `Max Accuracy` - Best-case performance
- `Total Correct/Total Questions`

### 3. Summary by Explanation Model
**File**: `summary_by_explanation_llm.csv`

Aggregated statistics for each LLM's explanations across all embedding models:
- `Mean Accuracy` - Average performance across all 9 embeddings
- `Std Accuracy` - Standard deviation
- `Min Accuracy` - Worst-case performance
- `Max Accuracy` - Best-case performance
- `Total Correct/Total Questions`

## Key Insights to Explore

After running the benchmark, analyze:

1. **Embedding Model Robustness**
   - Which embedding models have high mean accuracy?
   - Which have low standard deviation (consistent across all LLMs)?

2. **Explanation Quality**
   - Which LLM's explanations work best with embeddings?
   - Do "thinking models" (with reasoning) produce better explanations?

3. **Synergies**
   - Are there specific embedding+LLM pairs that excel?
   - Do certain embeddings pair better with certain explanation styles?

4. **Explanations vs. Raw Text**
   - Do explanations generally improve performance?
   - Are some embedding models better at raw text, others at explanations?
